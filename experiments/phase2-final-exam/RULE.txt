COMMON PROTOCOL
- Validation deal partition 0, start 0-0. Pair index i: target 15 for even i, 30 for odd i.
- A pair = two games on the same deal seed, evaluated network in seat 0 then seat 1.
- Every game constructs new policies, profiles and RNGs for both seats; nothing carries across games (do not reuse mirror helpers that keep profiles across a pair).
- Within one opponent block, every evaluated network (C1, C2, B, or each temperature) plays the same deal seeds and the same action seeds, by (block, i, game, seat). This makes per-pair differences paired.
- Pair score = (evaluated network's wins in the two games) / 2.
- At most 12 worker processes. Raw records (block, i, deal seed, target, decimal action seeds, both winners) are appended to partial.jsonl, flushed per record, fsync every 32 and at block ends. config.json records git revision, hashes of all project Python files, this rule, the tool, models and sidecars before play. A started.lock makes each part exclusive; an interrupted part may only finish its missing pairs deterministically.

PART T: TEMPERATURE (exploratory, run first)
- C1 at T in {0.05, 0.02, greedy}. Greedy = highest legal Q; ties go to the lowest action index.
- Opponents AU and P1, 300 pairs each. Blocks: t=0 AU, t=1 P1.
- Deal seed = 2*((90001 + t)*10^9 + i). Action seed = 2^131 + (((t*300 + i)*2 + game)*2 + seat).
- m(T) = equal-weight mean of C1's mean pair score vs AU and vs P1.
- T* = argmax m(T), ties broken toward 0.05 then 0.02; T* replaces 0.05 only if m(T*) - m(0.05) >= 0.02, else T* = 0.05. Report all three m(T) with paired intervals, descriptively.

PART E: EXAM (once, after Part T)
- Opponent blocks k = 0..4 as listed, 1000 pairs each; C1, C2 (both at T*) and B (T = 0.05) each play every block.
- Deal seed = 2*((91001 + k)*10^9 + i). Action seed = 2^130 + (((k*1000 + i)*2 + game)*2 + seat).
- For candidate c and opponent k: d_ck(i) = pair score of c - pair score of B; gain g_ck = mean over i; SE = sample SD of d_ck / sqrt(1000).
- Primary (AU, k=0): z_c = g_c0 / SE_c0, one-sided p_c = 1 - Phi(z_c). Holm over {C1, C2} at overall one-sided alpha 0.025: the smaller p is tested at 0.0125, and the larger at 0.025 only if the smaller passed. A test rejects when p <= its level. Primary passes for c if its Holm test rejects (gain > 0).
- Guardrails (k = 1..4): g_ck - 1.96*SE_ck > -0.02 for every k. A bound equal to the threshold fails.
- Balance: equal-weight mean of g_ck over k = 0..4 > 0.
- c passes if primary, all guardrails and balance hold.
- Decision: if C1 passes, C1 ships; else if C2 passes, C2 ships; else B stays. Report every gain, interval and win rate (including vs AU and whether above 50%) for both candidates and B, whatever the outcome.
