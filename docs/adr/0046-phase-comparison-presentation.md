# Phase comparison shows only the shipped phase 1 run, as a comparison of network modes

Status: accepted (user decision, 2026-11-08), fixed before any phase 2 result exists.

On the evolution page (ticket #26) phase 1 is represented only by the shipped run 1 (reigning-champion succession up to generation 48), the network the "Red neuronal · Neuroevolución" mode plays. The comparison is titled "Neuroevolución vs Aprendizaje por refuerzo" (both are neural networks; what differs is how they learned) and states that phase 2 also trained against phase 1 networks (ADR 0043), so it compares the two playable network modes and does not show that reinforcement learning beats neuroevolution in general. The v2 runs, some of which did better than run 1 in the round robin, are mentioned as a limitation in the written records, not drawn as extra series.

## Considered Options
