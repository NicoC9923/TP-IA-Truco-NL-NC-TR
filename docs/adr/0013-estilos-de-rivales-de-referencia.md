# Rivales de referencia con estilos fijos

Además del modo Reactivo y la Utilidad adaptativa, se usan cuatro variantes del agente de Utilidad con parámetros fijos: mentiroso (faroles altos), cauteloso (acepta poco), agresivo (sube mucho) y calculador (sin faroles). Hacen falta para que la adaptación por perfil (ADR 0012) tenga estilos distintos de los que aprender, y para que el agente no se especialice en un solo rival (ADR 0004).
