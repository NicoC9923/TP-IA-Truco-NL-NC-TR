# Relative score and matches that start from a random score

The network doesn't receive the target (15 or 30), but the points each player still needs and the current value of falta envido. That way what it learns about endgames holds for both targets, and one agent serves both. Training mixes matches to 15 and to 30, and 30% of them start from a random score, so the network practices close endgames more often than normal matches would give it.
